## О работе

Шесть лабораторных — одна сквозная работа: от требований к модели и коду. Предметная область
общая, поэтому модели согласованы между собой: прецеденты → классы предметной области →
системные последовательности → диаграммы коммуникаций → классы проектирования → реализация.

Рассматривается подсистема **«Действия после получения патента»**: контроль срока трудоустройства
(2 месяца с даты выдачи патента), заключение трудового договора или договора ГПХ, уведомление МВД
об осуществлении трудовой деятельности, учёт авансовых платежей НДФЛ и сроков действия патента.

Модели строятся только по разделу 7 дорожной карты. Разделы 1–6 (миграционный учёт,
дактилоскопия, медосвидетельствование, выбор порядка трудоустройства, документы для патента,
подача и получение патента) выступают предусловиями; разделы 8–11 (программа переселения,
господдержка, РВП, ВНЖ) в работу не входят.

## Структура

```
fms-course/
├── lab1-usecases/            # прецеденты: диаграмма, акторы, 7 спецификаций
├── lab2-domain-model/        # классы предметной области, инварианты, глоссарий
├── lab3-sequence-diagrams/   # 19 системных последовательностей + operations.md
├── lab4-communication-diagrams/  # 16 диаграмм коммуникаций
├── lab5-design-classes/      # классы проектирования + трассировка операций
└── lab6-implementation/      # реализация: код, тесты, README с запуском
```

В каждой папке — отчёт `README.md` (что сделано, принятые решения, открытые вопросы) и исходники
диаграмм в двух форматах: `.puml` (PlantUML) и `.md` (Mermaid, рендерится на GitHub). PNG —
готовые рендеры для просмотра без инструментов.

## Запуск реализации (лаб. 6)

```bash
cd lab6-implementation
uv venv && uv pip install -r requirements.txt
.venv/bin/python -m pytest            # 84 теста
.venv/bin/uvicorn app.main:app --port 8080
```

Демонстрационный сценарий из 7 запросов — `lab6-implementation/scripts/demo.sh`,
подробности в `lab6-implementation/README.md`. Документация API — `http://localhost:8080/docs`.
