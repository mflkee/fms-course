# ФМС: программная реализация

Дисциплина: Функциональное моделирование систем, ТюмГУ, 5 семестр.
Команда: Малышева Елена, Макеев Глеб.
Тема 7: действия после получения патента.

В репозитории хранится только программная часть работы (лабораторная 6): сервис на FastAPI,
10 операций и тесты. Документы по лабораторным 1-3 ведутся отдельно и в репозиторий не входят.

## Запуск

```bash
cd lab6-implementation
uv venv && uv pip install -r requirements.txt
.venv/bin/python -m pytest
.venv/bin/uvicorn app.main:app --port 8080
```

Схема API: <http://127.0.0.1:8080/docs>.
