# П06. Прекращение договора, смена работодателя и повторное уведомление МВД

| Поле | Значение |
|---|---|
| **Название** | Прекращение договора со прежним работодателем, смена работодателя и повторное уведомление МВД |
| **Рамки** | Подсистема «Действия после получения патента» |
| **Уровень** | Задача пользователя (пользовательский прецедент) |
| **Основной исполнитель** | Работодатель / заказчик по ГПХ (A2) |
| **Участники** | Работодатель (A2); Иностранный гражданин (A1); сотрудник ОВМ МВД (A3); ЕПГУ (A4); Почта России (A5) |
| **Связанные прецеденты** | Включает П03 (новое уведомление МВД); следует за П02; опирается на П04 |
| **Статус** | **Расширение, требует подтверждения преподавателем** — в дорожной карте прямо не описано, но необходимо для контроля инварианта «один действующий договор на патент» |

> **Примечание.** Пункты 7.1 и 7.2 дорожной карты описывают только первое трудоустройство.
> Смена работодателя и расторжение договора в документе не упомянуты, однако без них нельзя
> обеспечить корректность учёта: новый договор не может быть заключён, пока не закрыт прежний
> (см. инвариант в лаб. 2), а при смене работодателя работодатель обязан направить новое
> уведомление МВД. Прецедент включён как расширение темы 7.

## Заинтересованные лица и их интересы

| Лицо | Интерес |
|---|---|
| Работодатель (новый) | Принять ИГ без риска: прежние отношения должны быть корректно закрыты |
| Работодатель (прежний) | Снять с себя обязанности, иметь доказательство своевременного уведомления о прекращении |
| Иностранный гражданин | Сохранить легальность работы и патент при переходе к другому работодателю |
| Сотрудник ОВМ МВД | Актуальные и полные сведения об осуществлении трудовой деятельности |
| ФНС (закулисный интерес) | Корректное закрытие и открытие налоговых обязательств по договорам |

## Предусловия

- Существует действующий договор, зарегистрированный в подсистеме (П02) и, возможно,
  по которому уже направлено уведомление (П03).
- Патент учтён (П01) и действует; его профессия допускает работу у нового работодателя.
- Есть основание прекращения: расторжение по соглашению сторон, увольнение, истечение срока ГПХ,
  отказ от договора.

## Постусловия

- Прежний договор закрыт: зафиксированы дата и основание прекращения, договор помечен как
  «прекращён» и больше не считается действующим.
- Сформировано и направлено в МВД уведомление о новом договоре (или о прекращении отношений,
  если новый договор ещё не заключён) — через ЕПГУ или почтой, с копией документа.
- Инвариант «один действующий договор на один патент» восстановлен.
- Карта ИГ перестроена: если ИГ остался без работы, запущен контроль срока на трудоустройство
  (не позднее 2 месяцев с даты выдачи патента) и предупреждение о риске аннулирования.
- Файлы всех связанных документов сохранены в деле ИГ.

## Основной успешный сценарий

| № | Действия исполнителя | Отклик системы |
|---|---|---|
| 1 | Работодатель или ИГ инициирует прекращение договора | Система запрашивает основание и дату прекращения, показывает связанные уведомления |
| 2 | Исполнитель заполняет основание и дату | Система проверяет корректность даты (не ранее даты заключения, не в будущем без причины) |
| 3 | | Система закрывает договор: статус «прекращён», уведомление по нему переводится в историю |
| 4 | Работодатель формирует уведомление МВД о прекращении или о новом договоре | Система подготавливает уведомление и прикладывает копию договора/соглашения |
| 5 | Работодатель отправляет уведомление через ЕПГУ или почтой | Система фиксирует дату, канал и подтверждение отправки |
| 6 | ИГ регистрирует новый договор с новым работодателем | Система проверяет профессию по патенту и срок «2 месяца с даты выдачи патента» |
| 7 | | Система создаёт новую контрольную точку «уведомление МВД» по новому договору |
| 8 | | Система перестраивает карты ИГ и обоих работодателей, напоминания пересчитываются |

## Альтернативные сценарии

**2а. Дата прекращения раньше уже направленного уведомления.**
1. Система помечает последовательность как противоречивую и запрашивает подтверждение.
2. Факт сохраняется в истории с отметкой об исправлении.

**4а. Новый работодатель не найден.**
1. Система открывает и выделяет задачу «трудоустроиться» с оставшимся сроком (по П04).
2. ИГ получает предупреждение: при пропуске срока патент может быть аннулирован.

**5а. Уведомление о прекращении не отправлено.**
1. Система оставляет задачу открытой и эскалирует её (риск ответственности работодателя).
2. При просрочке создаётся инцидент для администратора (П07).

**\*а. Договор расторгнут досрочно по инициативе работодателя.**
1. Система фиксирует инициатора и основание, сохраняет подтверждающие документы.
2. ИГ получает обновлённый остаток срока на новое трудоустройство.

**\*б. Патент аннулирован из-за отсутствия уведомления.** 
1. Система переводит патент в статус «аннулирован» (см. П01, `*б`).
2. Все задачи по трудоустройству закрываются, ИГ получает уведомление о необходимости
   покинуть РФ или оформить иной статус.

## Специальные требования

- Все документы (прежний договор, соглашение о расторжении, уведомление, подтверждение отправки)
  хранятся бессрочно и связываются в одну цепочку по патенту.
- Система не допускает одновременного существования двух действующих договоров по одному патенту.
- Уведомление о новом договоре подчиняется тому же сроку, что и первое: не позднее 2 месяцев
  с даты выдачи патента (если этот срок ещё не истёк).

## Частота использования

При каждой смене работодателя или расторжении договора — по событию, обычно редко
(исходя из практики, не более одного-двух раз за срок действия патента).

## Открытые вопросы

- Нужно ли уведомлять МВД о самом прекращении договора, или достаточно уведомления о новом
  договоре? В дорожной карте не сказано.
- Кто обязан направить уведомление при ГПХ после расторжения — заказчик или ИГ?
- Считается ли уведомление по новому договору «вторым» для проверки срока (2 месяца с даты
  выдачи патента), если срок уже прошёл, но ИГ просто меняет работодателя?
