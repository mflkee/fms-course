# П04. Контроль срока трудоустройства и напоминания

| Поле | Значение |
|---|---|
| **Название** | Контроль срока «2 месяца с даты выдачи патента» и напоминания участникам |
| **Рамки** | Подсистема «Действия после получения патента» |
| **Уровень** | Вспомогательная функция (обеспечивает достижение целей П02 и П03) |
| **Основной исполнитель** | Иностранный гражданин (A1) |
| **Участники** | Иностранный гражданин (A1); Работодатель (A2); ЕПГУ (A4); Почта России (A5) |
| **Связанные прецеденты** | Включается в П01; контролирует П02, П03, П05, П06 |

## Заинтересованные лица и их интересы

| Лицо | Интерес |
|---|---|
| Иностранный гражданин | Быть вовремя предупреждённым, чтобы не потерять патент |
| Работодатель | Заранее знать о приближении срока уведомления, чтобы избежать штрафа |
| Сотрудник ОВМ МВД | Меньше нарушений по срокам среди учтённых патентов |
| Администратор системы (закулисный интерес) | Сводная картина по критическим срокам (используется в П07) |

## Предусловия

- Патент учтён в подсистеме (П01); известна **дата выдачи патента**.
- Задан справочник сроков и правила расчёта (2 месяца с даты выдачи патента; календарные месяцы).
- ИГ согласился получать напоминания и указал каналы связи (личный кабинет, e-mail, телефон, ЕПГУ).

## Постусловия

- Для патента рассчитаны контрольные точки со сроками:
  «заключён договор» — не позднее 2 месяцев с даты выдачи;
  «направлено уведомление МВД» — после договора и не позднее 2 месяцев с даты выдачи;
  «уплачен авансовый платёж» — по календарным месяцам действия патента;
  «истекает срок действия патента» — по дате окончания.
- По каждой точке отправлены напоминания в заданные моменты (например, за 30, 14, 7, 3 и 1 день).
- При приближении срока задача помечена критической; при просрочке зафиксировано нарушение и
  отправлено эскалирующее уведомление обеим сторонам.
- История напоминаний и реакции на них сохранена (дата, канал, статус доставки).

## Основной успешный сценарий

| № | Действия исполнителя | Отклик системы |
|---|---|---|
| 1 | ИГ подтверждает согласие на напоминания и выбирает каналы | Система сохраняет настройки уведомлений для профиля |
| 2 | | Система рассчитывает дедлайны от даты выдачи патента: 2 месяца на договор и на уведомление |
| 3 | | Система сравнивает дедлайны с текущей датой и определяет, какие точки ещё открыты |
| 4 | | В назначенные моменты система формирует и отправляет напоминание исполнителю точки |
| 5 | ИГ или работодатель выполняет действие (заключает договор, отправляет уведомление) | Система закрывает соответствующую контрольную точку и прекращает напоминания по ней |
| 6 | | Система пересчитывает оставшиеся точки и, если срок ещё не истёк, продолжает контроль |
| 7 | | При закрытии последней точки периода система формирует итоговую отметку «обязанности по патенту исполнены» |

## Альтернативные сценарии

**2а. Дата выдачи патента введена с опозданием, часть срока уже прошла.**
1. Система сразу помечает точки как критически оставшиеся и отправляет немедленное уведомление.
2. ИГ видит фактический остаток срока, а не «полные 2 месяца» с даты ввода.

**4а. Исполнитель не реагирует на напоминания.**
1. Система повторяет напоминание по другому каналу и повышает уровень критичности.
2. По истечении срока система фиксирует нарушение и эскалирует его администратору (П07).

**\*а. Патент аннулирован или признан недействительным.**
1. Система закрывает все точки с формулировкой «основание — аннулирование патента».
2. Напоминания по этому патенту прекращаются.

**\*б. ИГ выехал из РФ или сменил регион пребывания.**
1. Система приостанавливает напоминания по региональным точкам и запрашивает подтверждение статуса.
2. При подтверждении прекращения действия патента точки закрываются.

**\*в. Срок изменён (например, законодательно) в период действия патента.**
1. Система применяет новый срок только к патентам, выданным после вступления изменения в силу.
2. Для ранее выданных патентов срок пересчитывается, о пересчёте уведомляются обе стороны.

## Специальные требования

- Все расчёты сроков — в календарных днях и месяцах по правилам исчисления сроков; часовой пояс
  определяется по региону выдачи патента.
- Напоминания не должны дублироваться или приходить после закрытия точки.
- Если срок истекает до конца текущих суток, напоминание отправляется немедленно, независимо
  от расписания.
- Все изменения сроков и факты напоминаний протоколируются (для доказательства и для П07).

## Частота использования

Ежедневно (плановый контроль) в течение всего срока «2 месяца с даты выдачи патента» —
не более одного интервала на один патент.

## Открытые вопросы

- Какая дата считается «датой выдачи патента», если в патенте указана только дата решения
  или дата вручения?
- Нужно ли напоминать работодателю, если ИГ ещё не заключил договор (напоминание «о контакте»)?
- Требуются ли напоминания по каналам вне системы (SMS), и можно ли их считать доставленными?
- Что делать, если 2-месячный срок истекает в нерабочий день?
