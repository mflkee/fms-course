# П1. Заполнить анкету

| Поле | Значение |
|---|---|
| **Исполнитель** | Иностранный гражданин |
| **Цель** | Сообщить системе сведения о выданном патенте и о договоре, чтобы получить дорожную карту по разделу 7 |
| **Граница** | Только сбор и проверка данных. Сроки и правила здесь не применяются |
| **Результат** | Принятая анкета, сохранённая в системе |

Анкета содержит только то, что нужно пунктам 7.1 и 7.2: реквизиты патента и сведения о договоре.

## Основной сценарий

| № | Действия пользователя | Отклик системы |
|---|---|---|
| 1 | Открывает анкету | |
| 2 | | Показывает поля: серия и номер патента, дата выдачи, регион, профессия; сведения о договоре, если он заключён |
| 3 | Заполняет поля | |
| 4 | | Проверяет, что поля заполнены, даты в правильном формате и не в будущем |
| 5 | Подтверждает анкету | |
| 6 | | Сохраняет анкету и предлагает посмотреть дорожную карту (П2) |

## Альтернативные исходы

- **А1. Обязательное поле не заполнено.** Система не принимает анкету и подсвечивает пустые поля;
  ИГ дозаполняет и подтверждает снова.
- **А2. Дата выдачи патента позже сегодняшней.** Система показывает сообщение «дата выдачи не может
  быть в будущем»; ИГ исправляет дату.
- **А3. Патент ещё не выдан.** Система сообщает, что подсистема работает с уже выданным патентом,
  и анкету не принимает: выдача патента — раздел 6 дорожной карты, вне темы 7.
