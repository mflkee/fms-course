# П1. Заполнить анкету

| Поле | Значение |
|---|---|
| **Исполнитель** | Иностранный гражданин |
| **Цель** | Сообщить системе данные о себе, чтобы получить дорожную карту |
| **Граница** | Только сбор и проверка анкеты. Правила и сроки здесь не применяются |
| **Результат** | Принятая анкета, сохранённая в системе |

## Основной сценарий

| № | Действия пользователя | Отклик системы |
|---|---|---|
| 1 | Открывает анкету | |
| 2 | | Показывает поля: цель въезда, дата въезда, ранее пройденные процедуры |
| 3 | Заполняет поля | |
| 4 | | Проверяет заполненность и формат дат |
| 5 | Подтверждает анкету | |
| 6 | | Сохраняет анкету и предлагает перейти к дорожной карте (П2) |

## Альтернативные исходы

- **А1. Обязательное поле не заполнено.** Система не принимает анкету и подсвечивает пустые поля.
  ИГ дозаполняет и подтверждает снова.
- **А2. Дата въезда позже сегодняшней.** Система показывает сообщение «дата въезда не может быть
  в будущем». ИГ исправляет дату.
