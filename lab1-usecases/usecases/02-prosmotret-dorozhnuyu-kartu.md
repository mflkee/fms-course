# П2. Просмотреть дорожную карту

| Поле | Значение |
|---|---|
| **Исполнитель** | Иностранный гражданин |
| **Цель** | Узнать, какие действия нужно выполнить и к какому сроку |
| **Граница** | Система определяет категорию, считает сроки и формирует рекомендации. Выполнение действий (дактилоскопия, договор, уведомление) она не контролирует и не регистрирует |
| **Результат** | Дорожная карта: список рекомендаций со сроками |

Это прецедент, который отвечает за все правила. Изменение правила (например, нового срока для
категории) затрагивает только этот прецедент.

## Основной сценарий

| № | Действия пользователя | Отклик системы |
|---|---|---|
| 1 | Запрашивает дорожную карту | |
| 2 | | Берёт анкету, принятую в П1 |
| 3 | | Определяет категорию по цели и дате въезда |
| 4 | | Рассчитывает сроки по правилам категории |
| 5 | | Формирует пункты дорожной карты: что сделать и до какой даты |
| 6 | | Показывает дорожную карту |
| 7 | Просматривает пункты | |

## Альтернативные исходы

- **А1. Цель въезда — туризм.** Патент не нужен, система не формирует пункты про патент и
  показывает сообщение «для вашей цели въезда трудовой патент не требуется».
- **А2. Срок уже истёк.** Пункт помечается «срок истёк», система показывает предупреждение о риске.
- **А3. Анкета не заполнена.** Система не строит карту и отправляет пользователя к П1.
