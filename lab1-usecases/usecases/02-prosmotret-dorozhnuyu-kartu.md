# П2. Просмотреть дорожную карту

| Поле | Значение |
|---|---|
| **Исполнитель** | Иностранный гражданин |
| **Цель** | Узнать, что нужно сделать по пунктам 7.1 и 7.2 и до какого срока |
| **Граница** | Система считает сроки и формирует рекомендации. Сами действия (трудоустройство,
  уведомление МВД) она не выполняет и не контролирует |
| **Результат** | Дорожная карта из пунктов 7.1 и 7.2 со сроками и статусами |

Это прецедент, который отвечает за все правила раздела 7. Изменение правила (например, срока)
затрагивает только этот прецедент.

## Основной сценарий

| № | Действия пользователя | Отклик системы |
|---|---|---|
| 1 | Запрашивает дорожную карту | |
| 2 | | Берёт анкету, принятую в П1 |
| 3 | | Формирует пункт 7.1: «трудоустроиться не позднее <дата выдачи патента + 2 месяца>» |
| 4 | | Если в анкете указан договор — формирует пункт 7.2: «уведомить МВД, не позднее той же даты» |
| 5 | | Показывает дорожную карту: пункты, сроки и статусы |
| 6 | Просматривает пункты | |

## Альтернативные исходы

- **А1. Срок 7.1 истёк.** Пункт помечается «срок истёк», система показывает предупреждение о риске
  для патента.
- **А2. Договор ещё не заключён.** Пункт 7.2 не показывается: сначала нужно закрыть 7.1, а срок
  уведомления отсчитывается от даты договора.
- **А3. Анкета не заполнена.** Система не строит карту и отправляет пользователя к П1.
