## 3. Сообщения

| № | Сообщение | Отправитель | Получатель | Назначение |
|---|---|---|---|---|
| **1** | `направитьУведомлениеМВД(номерДоговора, канал)` | ЭкранУведомления | СервисУведомлений | Точка входа: работодатель отправляет уведомление по заключённому договору. |
| **1.1** | `найтиПоНомеру(номерДоговора)` | СервисУведомлений | РепозиторийДоговоров | Уведомление строится только по заключённому договору. |
| **1.2** *(возврат)* | `Договор — статус «заключён»` | РепозиторийДоговоров | СервисУведомлений | Договор — источник данных для уведомления. |
| **1.3** | `проверитьСрокУведомления(дата)` | СервисУведомлений | Договор | ИНВ-2: уведомление не ранее договора и не позднее 2 месяцев с его даты. |
| **1.4** *(возврат)* | `СрокСоблюдён — да` | Договор | СервисУведомлений | При нарушении срока уведомление всё равно формируется, но помечается как просроченное. |
| **1.5** | `подготовитьКопию(договор)` | СервисУведомлений | Документ | Копия договора — обязательное приложение к уведомлению. |
| **1.6** | `адресатПоРегиону(кодРегиона)` | СервисУведомлений | ТерриториальныйОрганМВД | Территориальный орган МВД определяется регионом патента. |
| **1.7** *(возврат)* | `ТерриториальныйОрганМВД — код, наименование, адрес` | ТерриториальныйОрганМВД | СервисУведомлений | Реквизиты адресата для уведомления. |
| **1.8** | `сформировать(договор, орган, канал, копияДоговора)` | СервисУведомлений | УведомлениеМВД | Уведомление создаётся со статусом «подготовлено». |
| **1.9** | `[канал = ЕПГУ] отправить(уведомление, копияДоговора)` | СервисУведомлений | ШлюзЕПГУ | Отправка через ЕПГУ; протокол обмена не детализируется. |
| **1.10** *(возврат)* | `[канал = ЕПГУ] ПодтверждениеОтправки — номерКвитанции` | ШлюзЕПГУ | СервисУведомлений | Квитанция — доказательство отправки. |
| **1.11** | `[канал = почта] отправить(уведомление, копияДоговора)` | СервисУведомлений | ШлюзПочты | Альтернативный канал: заказное письмо с описью вложения. |
| **1.12** *(возврат)* | `[канал = почта] ПодтверждениеОтправки — трекНомер` | ШлюзПочты | СервисУведомлений | Трек-номер — доказательство отправки. |
| **1.13** | `зафиксироватьОтправку(номерКвитанции / трекНомер, датаНаправления)` | СервисУведомлений | УведомлениеМВД | Уведомление получает статус «направлено» и доказательства. |

## 4. Решения и примечания

- Два шлюза на одной диаграмме — это альтернатива по каналу: сообщения 1.9–1.10 выполняются только для ЕПГУ, 1.11–1.12 — только для почты (страж `[канал = …]`).
- `ТерриториальныйОрганМВД` — сущность, а не шлюз: это адресат, а не канал передачи. Канал — `ШлюзЕПГУ` или `ШлюзПочты`.
- Система не отслеживает статус рассмотрения уведомления: она фиксирует только факт отправки и доказательства (DESIGN §0, п. 5).
- Смена работодателя требует нового уведомления (ИНВ-7) — это новая карточка `УведомлениеМВД`, а не правка прежней.
